- **`min_bars_per_day = 280` の固定**: 初日 `2024-04-05`（193 本）を除外し、`2024-04-08` 〜 `2024-12-31` の `191` 完全日（各 `288` 本）を有効日とする。
- **日次 RV 定義の一致**: 既存 `unit:hamilton_pred_prob`（[unit_registry.py](file:///c:/Users/ksato/workspace/finance/algoforge_pipeline/src/research_pipeline/integration/unit_registry.py)）の `ret[i] = (close[i] - close[i-1]) / close[i-1]`、`rv_day = sum(ret[day]^2)`、`log_rv = log(rv_day)` を評価ラベル側でも**完全同一定義**で使用する（週末・休場日を跨ぐ最初のバーも `ret[i]` に含まれる点は Unit と評価ラベルで一致しており、実装変更は行わない）。

## 2. Hawkes (`unit:hawkes_hazard`) 評価契約

- **評価ペア**: バー $t$ 終値確定後の $h_t^{\text{post}}$ と次バー $t+1$ のイベント $y_{t+1}$（閾値標準偏差はバー $t$ までの情報で算出）を対応させる。
- **ギャップ除外**: `time[t+1] - time[t] > 300s` のギャップを跨ぐ評価ペア $(t, t+1)$ は除外する。
- **指標**: 主指標 **ROC-AUC**、補助指標 **5 分位別イベント率**（Brier / 対数尤度は除外）。IS / OOS それぞれの有効ペア数・正例数・イベント率を報告する。

## 3. Hamilton (`unit:hamilton_pred_prob`) 評価契約

- **評価ペア**: 日付 $d$ の予測確率 $\xi_{d \mid d-1}[1]$ と日付 $d$ の観測 `log_rv[d]` を対応させる（潜在状態確率を観測高ボラ日確率と同一視しない）。
- **指標**: 主指標 **Spearman 順位相関**、補助指標 **5 分位別 `log_rv`**。IS / OOS の有効日数（IS 65 日・OOS 66 日）と欠損日数（0 日）を報告する。

## 4. 追加情報価値（層別化評価）

- **主比較**: ベースライン単独と Unit 単独の OOS 指標差（$\Delta \text{AUC}$、$\Delta \rho_{\text{Spearman}}$）を評価する。
- **補助評価**: ベースラインを **3 分位（Tercile）** に分割し、各分位内での Unit の条件付き関係（Hawkes: AUC / イベント率、Hamilton: Spearman 相関 / 平均 `log_rv`）を評価する。各分位の最小サンプル数は **Hawkes 500 ペア（正例 10 件以上）、Hamilton 15 日** とし、未満の場合は「評価不能（`N/A`）」とする。線形残差化・比較モデルの新規学習は除外する。

## 5. 不確かさ推定（ブロック・ブートストラップ）

- **手法**: UTC 営業日単位の **ペア・ブロック・ブートストラップ**（主解析：ブロック長 `5` 営業日、感度分析：ブロック長 `10` 営業日、反復回数 `2,000` 回、固定シード `42`）。
- **報告**: OOS 指標差の **95% 信頼区間**（2.5%〜97.5% パーセンタイル）を報告する。OOS 結果に基づく評価方法の変更は禁止する。
